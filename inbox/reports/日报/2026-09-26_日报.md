### 美投 9/25 日报

**观点 1：中美会谈是稳住局面，不是突破**
- 逻辑：三天会面规格很高（红毯、国宴），但成果很少 → 唯一具体的是休战从 11 月延到 2027-1-10，此外还有两只熊猫；内容是美国下调关税、中国暂停稀土和关键矿产出口管制 → AI、伊朗、大额采购没有新协议，AI 安全通报机制没落地 → 中期选举只剩一个多月，川普要平静，美方态度是"先不要出事"。

**观点 2：市场要的不是大突破，而是风险不再恶化**
- 逻辑：路透报道美伊在研究分阶段方案（重启霍尔木兹海峡、解除经济封锁），离协议还远 → 但停火预期升温，油价下跌 → 美债收益率回落。中美休战也一样：11 月到期会在通胀敏感期多一个不确定因素，现在被挪到选举之后 → 川普不会急着在选举前解决美伊、中美贸易和 AI 竞争，只要不恶化，油价和关税风险就能压住。
- 数据：周五 WTI -2.3%（连续第二周下跌），两年期收益率 -7bp，曲线陡峭化。

**观点 3（周总结）：本周核心叙事是美债收益率大幅上行**

### qinbafrank（2 条）

**观点 1：Ackman 的"加息可能推高通胀"有一半道理**
- Ackman 的逻辑：加息压通胀的前提是压低需求和投资 → 但算力和能源需求不受利率影响，因为赢得超级智能竞赛的回报近乎无限 → 加息反而把利息成本嵌进所有价格 → 通胀上升 → 美联储被迫再加 → 恶性循环。
- qinbafrank 认可：大型云厂商为抢 AGI，资金成本上升不会让它们停手；利率本身是成本，会转嫁；通胀若主要来自供给短缺，加息可能恶化短缺；当前通胀脉冲很大程度来自中东冲突推高的油价，美联储管不了。
- qinbafrank 不认同：AI 投资只是经济的一部分，住房、汽车、耐用品、中小企业投资、消费信贷对利率非常敏感，加息会冷却它们。2022–23 年利率从近 0 加到 5% 以上，CPI 从 9% 降到约 3%；反向操作的土耳其通胀飙到 80%。
- 结论：AI 的特殊之处是短期需求先到（建数据中心、抢电力、抢芯片），生产率提升后到，所以通胀粘性更强。加息压不住 AI 基建，但能压住非 AI 需求，对冲后通胀不会那么强。关键看两点：能源冲击何时缓解、AI 生产率何时兑现（他 8 月底提出的"四个时钟"里最后一个）。

**观点 2：习访美的最大成果是美国接受了 G2 状态，中美关系从"危机管理"回到"框架管理"**
- 逻辑：中方定性"建设性战略稳定关系"，白宫称"历史性国事访问"、"公平互惠"，这是 5 月川普访华定位的深化 → 具体进展：
  - 深圳 APEC（11/8）和迈阿密 G20（12/14）再见面。
  - 伊朗问题上同意伊朗应履行不发展核武器的承诺，任何一方不得对国际水道征收通行费。
  - 300 亿美元对等降税，细节要在 2027-1-10 前谈完。
  - 禁毒合作和 AI 对话。
- 判断：竞争不会少，但强调"有度、可控"，红线是"不摊牌"。
- 注意：他引用的 5/18 自己的旧帖里提到的波音 200 架（传闻 500–750 架）、没有芯片、稀土短期不再卡脖子，是 5 月的判断，不是这次的。

# 二、半导体与 AI

## 核心信源

### 投资TALK君 1498：Oracle 木星计划（7 个观点）

**1. 这是 Oracle 的执行力风险，不是需求风险，也不是信用风险**
- 逻辑：木星计划是 2025 年 Oracle 与 OpenAI 五年 3000 亿美元订单中的一个项目，在新墨西哥州建 4 座数据中心，共 2.4GW → 天然气管道审批推迟到 2027 年 2 月，空气许可证也没下来 → 交付延后 → Oracle 给 OpenAI 的算力延后，营收确认延后 → 这只影响未来营收，不是现金损失。木星计划交付时间是 2028 年，近期财年营收不受影响。

**2. 为什么 Oracle 自己没有直接损失**
- 逻辑：OpenAI 要算力 → Oracle 负责提供，但自己不是开发商 → 与 Bloom Energy 合作，其下的基建公司开发，并设立 SPV 负责贷款 → Oracle 对 SPV 提供的是未来现金流的承诺（他说严格来说不算担保）→ SPV 凭这个承诺向 20 多家中小型银行借 180 亿美元。这是北美常见的项目融资，类似政府承诺医院建成后每年拨款，开发商凭此融资。

**3. 不可抗力通知的目的是保护自己**
- 逻辑：数据中心没建好，Oracle 就不该付租金 → 发出不可抗力通知，是为了延误时可以延期付租金。
- 数据：Bloom Energy 当天下午与 Oracle 沟通，确认 2.4GW 订单没取消，只是时间可能延后。

**4. 180 亿美元贷款报价降到 89–90 美分，有四个原因**
- 加息：贷款条款是 SOFR+250bp，联邦利率刚加了 25bp。但他认为加息只能解释一小部分，不能解释跌近 10%。
- Oracle 信用风险上升（他认为主因）：Oracle 是现金流承诺方，它的信用变差，被承诺的项目价格自然下降。
- 流动性折价：这类贷款转手要打折。
- 项目完成风险：延期就是完成风险上升。
- 提示：他一边说信用风险是主因，一边说"这不是信用问题、是执行力问题"，两句话有张力，引用时要小心。

**5. 现在的瓶颈是电力，不是 GPU**
- 逻辑：电网供电排队要 5–6 年 → 改用涡轮发电，涡轮产能紧张，柴油又有污染（相关公司有 Caterpillar、GE Vernova、西门子）→ 改用 Bloom Energy 的天然气燃料电池 → 燃料电池需要天然气管道 → 管道审批卡住了整个项目。
- 补充：GPU 和互联不是瓶颈，HBM 仍是瓶颈。

**6. 对行业未必是坏事：有执行力的新云受益，泡沫形成被放缓**
- 逻辑：原计划 2028 年上线的 2.4GW 算力上不了 → 只要需求仍在增长，就说明需求大于供给 → 其他能把数据中心建起来的云公司受益，这也是周四 Nebius 和 CoreWeave 上涨的原因 → 泡沫的判据是供给超过需求，交付延后反而放缓泡沫形成。
- 风险链：OpenAI 依赖 → Oracle 的融资和执行风险 → 开发商建设延后 → 电力风险 → 交付延后 → 营收风险。大云融资风险低，新云融资风险高，新云未来一定要融资。

**7. 反驳彭博记者 Anna Wang 的"会有更多类似情况"**
- 逻辑：他认为这是公司特定风险，不是行业信用风险。如果后续项目继续延期，每次都会造成股价下跌；如果按原计划执行，这次的下跌可以涨回来。

### 美投 9/25 日报

**观点 4：微软新版 Copilot 对微软整体利好（美投 Tim）**
- 逻辑：4.5 亿商业版 Office 365 账号，购买 Copilot 的不到 7% → 新应用整合 Code、Cowork、Autopilot，Autopilot 让企业建自己的 Agent，并直接在 Teams 和 Outlook 里沟通 → 三者按量计费（原 365 Copilot 是每人每月 30 美元固定）；模型可选 OpenAI、Anthropic 或微软自研 → 微软已有企业入口，不必从零抢，用户形成使用 Agent 的习惯后，Office 生态就是优势。
- 保留意见：Office 的黏性不一定能转移到 Autopilot，要看能否真的省时间。Tim 认为微软在消费者端不一定能赢。

**观点 5：AI 价值正向行业应用扩散，上游机会没有结束**
- 逻辑：OpenEvidence 融资 2.5 亿美元，估值从 1 月的 120 亿涨到 150 亿 → 超三分之二的美国医生在用，8 月有 4200 万次咨询 → 医疗对准确性要求极高，医生仍长期使用，说明产品可靠 → 对医生免费，靠广告变现，用户规模已在转化成收入 → 应用越高频，算力需求越稳；法律、金融、教育若出现类似应用，需求会层层叠加 → 该公司甚至要求被收购时把算力打包进交易，因为担心反 AI 情绪会限制数据中心扩建 → 结论：算力需求从阶段性的训练延伸到长期的推理。

**观点 6：消费级 AI 从一家独大走向多家竞争，竞争焦点转为黏性（引伯恩斯坦）**
- 逻辑：ChatGPT 仍领先，但份额在降 → 不是用户减少，而是整个市场涨得比它更快 → 下载端开始降温，新用户红利见顶 → 竞争转向留存和使用频率 → 用户已经像用搜索和社交媒体一样使用 AI。
- 数据：ChatGPT 月活份额从 74%（去年三季度）降到 64%（今年 8 月），Gemini 从 22% 升到 26%。ChatGPT 日活/月活约 45%，月活同比 +70%。5–8 月新增月活里，ChatGPT 占 55%，Gemini 占 36%，Claude 占 12%。用户平均每天打开 8–9 次，使用 14–17 分钟。
