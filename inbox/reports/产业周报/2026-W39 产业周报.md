# 2026-W39 产业周报（9/21–9/27）

## 1. 产业：半导体 / AI 看供需，加密看政策和大事件

> [!summary] 结论
> 1. **AI 需求没有出现拐点：既没有转弱，也看不到再加速。** 访谈里没人给出需求转弱的证据，高频用量处在高位盘整；分歧在"谁拿走需求"：开源模型拿走 token 份额，前沿模型保住高价值任务，Agent 把需求从 GPU 扩到 CPU。
> 2. **供给侧本周的新变化是"建不起来"，而不是"不想建"。** 木星计划、SB Energy 推迟 IPO 同时出现，<span style="color:red">瓶颈从芯片转向电力、审批和融资</span>，效果是供给后移、供不应求拉长。
> 3. **存储：涨价在放缓，但 2027 年的紧张更确定。** 合约价环比涨幅从 Q2 约 60% 收窄到 Q3 13–18%，消费类价格已见顶；但需求高于年初预期，HBM 新产能大部分在 2027 年后才释放，厂商用长单锁定 2026–2027 年，服务器 DRAM 约 2027 年中见顶，NAND 紧张到 2027 年底。反方是 Burry：普通 DRAM 产能恢复后价格会承压（宏碁也称压力约在 2027 年底显现）。<span style="color:red">下周 MU 财报是验证点</span>。
> 4. **加密监管从立法转向行政规则，但推动者即将离任。** Clarity 法案未过参议院，一周内 SEC、CFTC、美联储接连出规则和提案，方向偏松；但<span style="color:red">最主要的推动者 Peirce 10/2 离开 SEC，持续性存疑</span>。Bitget 被盗是交易所事件，不是 BTC 供给冲击。

### 1.1 半导体 / AI：本周访谈

> 每期统一格式：标题写一句话主结论 → 原文链接 → 结论要点列表（结论：逻辑与数据 · 供需归类）→ 需要提醒的放在"注意"。

#### ① 美投 Phoenix 直播（9/21）：景气还在向上，市场只定价到 2027 年
原文：[[收集箱/周读/美投 2026-09-22_macro_Pm0Fd-TOFU_【直播回放】半导体大涨过后，仍有巨大潜力尚未释放？哪一个细分板块最值得关注？|美投 Phoenix 直播回放]]

- **七八月跌的是预期，不是基本面**：费城半导体指数七八月最大回撤接近腰斩，原因是韩国 ETF 杠杆爆仓、加息预期和"资本开支能否持续"的担心 → 但 8 月底博通、英伟达财报对前景更乐观 → 股价和基本面出现落差。*供需归类：需求未出现拐点*
- **景气高，而且边际在加速**：25 家硬件公司 Q2 中位数收入同比 +30% 多、净利润同比 +95%，收入和利润的同比、环比大多好于 Q1。*供需归类：需求加速（报表口径）*
- **存储：涨价斜率放缓，但 2027 年紧张更确定**：Q2 收入主要靠涨价，不是放量 → 合约价环比从 Q2 约 60% 降到 Q3 13–18% → 但需求高于年初假设，HBM 产能大部分在 2027 年后才释放 → 厂商用长单锁定 2026–2027 年 → 消费类已见顶，服务器 DRAM 约 2027 年中见顶，NAND 紧张到 2027 年底。*供需归类：需求边际拐点（价格端）+ 供给释放在 2027 年后*
- **光互联的景气比存储更长**：速率提升、机柜内"光进铜退"、多站点互联（单站点受政策限制）都是新增量 → 多数公司展望到 2028 年，康宁到 2030 年。*供需归类：中长期需求*
- **算力没有失速**：Q3 指引环比较低是季节性，Q4 才是主力出货 → 英伟达、博通对出货的乐观看到 2028 年；新增量来自新云、主权需求，以及博通的多年多款 ASIC 合同。*供需归类：需求延续*
- **设备订单决定供给何时释放**：设备商积压订单显示 2027 年存储扩产大年，2028 年转向先进制程 → 设备股最好的阶段贴着"最紧缺"，预期缓解时最好阶段就过去了。*供需归类：供给释放时点*
- **市场只定价 2027 年，产业对 2028 年仍乐观**：台积电持续上调资本开支，新产能要一年半才出来，等于押注 2028 年需求；台积电会调研"客户的客户"。*供需归类：中长期需求*

> 注意：他自己给的风险是，未来两年的指引建立在云厂商和大模型公司的预期上，离终端用户还有一截；Anthropic 或 OpenAI 的收入一变，指引就会跟着改。

#### ② 投资TALK君 1495 / 1496（9/20–9/21）：硬件调整近尾声，Agent 行情落在 CPU
原文：视频转录见 [[收集箱/每日/2026-09-21_日报|9/21 日报]]、[[收集箱/每日/2026-09-22_日报|9/22 日报]]

- **硬件调整接近底部，下半年软硬件可能一起涨**：7 月以来半导体约 -17%，估值从 28–29 倍降到约 18 倍，仓位已空 → 最悲观的时点可能已过 → AI 落地会体现在软件上 → Agent 故事会加速，但比他 7 月想的慢。*供需归类：需求未出现拐点*
- **周一芯片大涨是"故事线切换"，不是新的基本面**：市场交易的是 Muse 带来的 CPU 需求 → 轮到英特尔、AMD、Arm，交易 ASIC 时才轮到博通 → 个股跑输板块不代表基本面变坏。*供需归类：需求结构从 GPU 扩到 CPU*

> 注意：CPU:GPU 比例目前只有外部估计（4:1–40:1），不能外推成全市场需求。

#### ③ 投资TALK君 1498（9/24）：木星计划是甲骨文的执行风险，供给后移反而拉长供不应求
原文：视频转录见 [[收集箱/每日/2026-09-25_日报|9/25 日报]]、[[收集箱/每日/2026-09-26_日报|9/26 日报]]

- **瓶颈是通电，不是 GPU**：电网排队 5–6 年 → 涡轮也缺 → 改用 Bloom 燃料电池 → 依赖天然气管道 → 管道审批推到 2027 年 2 月，卡住 2.4GW 项目。*供需归类：供给电力约束*
- **是执行风险，不是需求问题，也不是行业信用事件**：订单没取消，交付后移；甲骨文损失的是未来营收，不是现金；180 亿美元贷款的借款人是 SPV，报价在面值 89–90 美分。*供需归类：供给后移，需求不变*
- **供给后移会放慢泡沫形成**：泡沫 = 供给超过需求 → 需求仍在增长时，供给上不来会拉长供不应求 → 能交付的云（Nebius、CoreWeave）受益。*供需归类：供需缺口拉长*

> 注意：他前后说法有张力：一处说贷款跌价的主因是甲骨文信用变差，另一处又说"不是信用问题"。

#### ④ 美投日报（9/24–9/25）：数据中心的阻力正在从单个项目变成行业约束
原文：[[收集箱/每日/美投 2026-09-24_news_42jV7-TOFU_Meta血洗三大行业！;数据中心卖不动？;下个月继续加息？麦当劳六年来最大机会！|美投 9/24]]、[[收集箱/每日/美投 2026-09-25_news_6Vhpx-TOFU_甲骨文喊不可抗力！;美债最大的风险！;Meta上涨才刚刚开始？AI三巨头报团！|美投 9/25]]

- **数据中心融资碰壁，主因是客户集中**：SB Energy（10GW、全部租给 OpenAI、没有一座已投运）推迟 IPO 到 10 月中下旬，主因是客户集中，次因是用水、电网、空气许可。*供需归类：供给融资约束*
- **阻力正在行业化，短线压订单兑现**：当地反对、审批和能源从单个项目扩散（德州也在查数据中心用水）→ 半导体、服务器、电力设备的订单兑现后移，短线有压力。*供需归类：供给约束行业化*
- **中长期是"有摩擦的扩张"**：只要 AI 逻辑还在，摩擦会让市场更谨慎，和没有阻力的互联网泡沫不同；延期还可能让甲骨文分散对 OpenAI 的依赖，仍看好下季度 OCI。*供需归类：中长期需求不变*

> 注意：和 ③ 的分歧在于性质：TALK君认为是甲骨文的公司特定风险，美投认为在变成行业约束。

#### ⑤ All-In（9/26）：模型趋同，token 需求流向开源，前沿公司被迫往上走
原文：[[收集箱/周读/2026-09-26 BidClub Anthropic IPO at Risk, Meta’s Muse Pop, Token Prices Fall, Open Source Gains Share, Alignment Fails|All-In E290]]

- **Friedberg / Chamath：模型趋同，token 份额转向开源**：过去 10 天密集发布 DeepSeek 4.1 Flash、Qwen、小米 MiMo Pro、Opus 5.5、GPT-6 Sol/Luna、Grok 4.7 → 模型差距进入误差范围 → 优势转到包在模型外的 Agent 框架 → 企业会换便宜模型或自建开源。数据：Vercel 图显示 12 周内 token 用量从"闭源 80 / 开源 20"翻到"开源 80 / 闭源 20"。*供需归类：需求结构从前沿 API 转向开源*
- **Sacks（反方）：前沿仍是稳定的双寡头**：10–30% 的高价值任务（工程、数学、生命科学、对冲基金）愿意付高溢价 → 收入还在涨，虽然 token 份额在丢。数据：未来一年全球新增算力约 60% 给了 Anthropic 和 OpenAI。*供需归类：需求前沿算力仍集中*
- **Anthropic IPO 会推迟并打折**：Anthropic 从 10 月推到 11 月或更晚，OpenAI 说 2027 年；<span style="color:red">年内上市概率 96% → 76%</span>。Chamath 的粗略例子：干净 IPO 可能 2 万亿美元，现在 1 万亿或更低。*供需归类：供给前沿公司融资节奏放慢*
- **经济押注在 AI 投资周期上**：木星计划"只是一座数据中心"（Friedberg）；通胀 3.5%、名义 GDP 5%，实际增长 1.5% 里 AI 可能占大部分，这个周期不能停（Chamath）。*供需归类：需求规模宏观依赖 AI 资本开支*

> 注意：Vercel 只是一家网关的口径（日报里同一来源是 Anthropic 支出份额 69% → 40%）。我的判断：token 总需求没减，但从少数前沿 API 分散到开源自建（如 Jane Street 签 190 亿美元云合同），对算力偏利好，对前沿模型的定价权和 IPO 估值偏利空。

### 1.3 加密：政策与大事件

**政策（方向：立法失败后转向行政规则）**
- **Clarity 法案在参议院以 49:50 未过**，白宫顾问称跛脚鸭会期通过的可能性很小，重心转向 SEC、CFTC 的现有授权。风险是没有立法时，规则和豁免可能被起诉。
- **一周内四个行政动作**：SEC 为代币化 NMS 股票开了交易路径（9/17）；CFTC FAQ 允许客户资金投资于代币化的获准品种（9/24）；美联储发布 GENIUS 稳定币提案，含分层资本费、两个工作日内赎回（9/24）；SEC 员工 FAQ 放宽协议持续开发和流动性质押的证券认定。
- **人事**：最主要的推动者 Hester Peirce **10/2 离开 SEC**，政策持续性取决于继任者。
- **稳定币出海**：彭博称华盛顿在考虑用公私合资推动美元稳定币的海外使用，目前没有时间表。

**大事件**
- **Bitget 被盗约 3.875 亿美元**（从 3.516 亿上调，差额是补计，不是新盗），被盗资产里没有 BTC，保护基金承诺全额覆盖。**提币 9/28 16:00 分批开放**，<span style="color:red">这是挤兑测试</span>。
- **币安以约 1 亿美元入股 Circle**，并签五年协议，USDC 进入币安钱包。在更严的稳定币规则下，份额更可能向头部发行商集中。
- 价格背景：BTC 本周 +3.2%（81,732 → 84,309），突破 8.3 万美元的前高，突破里有空头回补成分。

**补充**
- **本周数据一句话**：推理用量高位盘整（OpenRouter 30 日 +55%，但增速逐周下降），token 单价 90 天跌约 44%，新卡紧、旧卡松（B200 租金季度约翻倍，H100 走弱），存储合约价涨幅从 Q2 约 60% 收窄到 Q3 13–18%。需求没有转弱，也看不到再加速。
- **口径提醒**：All-In 说 Anthropic 和 OpenAI 都降价约 50%，日报里 Opus 5.5 只降 20%（4/20 美元），OpenAI 的 -50% 是相对促销价。
- **过滤掉的访谈**（和 AI 供需关系弱）：a16z 嘻哈、Replit、Hilton & Pratt、Bending Spoons、AppLovin（发现式广告不会被 Agent 替代）。
